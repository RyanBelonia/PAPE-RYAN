Sistema 3D de planeamento de interiores desenvolvido em Unity, focado na criação rápida de ambientes, posicionamento de móveis e edição interativa de espaços em tempo real.

O projeto foi concebido como uma ferramenta moderna de visualização e design de interiores, permitindo ao utilizador criar divisões, gerar salas automaticamente e decorar ambientes através de um sistema modular de móveis.

🛠️ Tecnologias Utilizadas
Unity 6
C#
Unity Input System
TextMeshPro
URP (Universal Render Pipeline)
