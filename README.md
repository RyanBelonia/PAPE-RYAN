#  InteriorPlanner 3D

Sistema 3D de planeamento de interiores desenvolvido em Unity, focado na criação rápida de ambientes, posicionamento de móveis e edição interativa de espaços em tempo real.

O projeto foi concebido como uma ferramenta moderna de visualização e design de interiores, permitindo ao utilizador criar divisões, gerar salas automaticamente e decorar ambientes através de um sistema modular de mobiliário.

##  Tecnologias Utilizadas
Este projeto tira partido de tecnologias modernas para garantir uma experiência de design fluida e imersiva:

- **Engine:** Unity 6
- **Linguagem:** C#
- **Renderização:** URP (Universal Render Pipeline)
- **Interface:** TextMeshPro
- **Input:** Unity Input System
- **Hardware VR:** Meta Quest 2 com Meta Horizon Link

---

##  Funcionalidades Principais
- **Geração Processual:** Criação de salas com dimensões personalizadas via código.
- **Sistema de Edição:** Manipulação precisa de objetos (posição, rotação e escala) em tempo real.
- **Persistência de Dados:** Sistema de Save/Load utilizando ficheiros JSON.
- **Ferramentas de Design:** Balde de tinta para personalização de materiais e biblioteca de objetos modular.
- **VR Ready:** Otimizado para imersão total com Meta Quest 2.
